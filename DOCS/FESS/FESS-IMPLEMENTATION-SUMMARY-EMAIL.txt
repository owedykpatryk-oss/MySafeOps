--------------------------------------------------------------------------------
1. PURPOSE
--------------------------------------------------------------------------------

This work builds a dedicated FESS workspace inside MySafeOps, mapped from your
real MC reference jobs (2SFG, Cranswick, Quorn, Butternut Box, Dovecoat, etc.).
It is not generic food/pharma branding for all customers — it is org-exclusive
for the FESS Group tenant (slug: fess-group).

Day-one workflow supported:
  • Pick client site → apply job starter → RAMS + Method Statement + PTW
  • Standard site RA baseline (~21 M&E rows) on every job
  • Line clearance / LOTO permits on live production lines
  • Site permit controller sign-off (client portal + RAMS fields)
  • FESS Site Pack PDF for site handover (RAMS + 5-page MS + registers + PTW)
  • Mobilise site in one click (G&HP, LOTO, contacts, briefing)
  • Publish client portals to cloud for permit controller RAMS approval

--------------------------------------------------------------------------------
2. ORG DETECTION & EXCLUSIVITY
--------------------------------------------------------------------------------

FESS features activate only when:
  • Organisation slug is fess-group (or fess_group), OR
  • Organisation name includes "FESS Group"

Safeguards for other tenants:
  • Modules fess-setup and fess-sites hidden from More menu and dashboard
  • FESS playbooks, job starters, client sites, portal presets filtered out
  • FESS RAMS/MS/project fields stripped on save for non-FESS orgs
  • Org-exclusive quick packs not shown elsewhere
  • fess_* hazard IDs hidden from RAMS library search for non-FESS orgs
  • Storage scrub on org switch removes FESS presets (portals, briefings, packs)

Key files:
  src/utils/fessOrg.js
  src/utils/fessExclusive.js
  src/utils/hiddenModules.js

4. CLIENT & SITE DIRECTORY (MAIN ENTRY POINT)
--------------------------------------------------------------------------------

Module: fess-sites (FESS client & sites)
Also shown on Dashboard for FESS org only.

Six food factory sites from MC references:
  • 2SFG Scunthorpe — DOLAV/MEYN (typical job)
  • 2SFG Flixton — grille M&E
  • Cranswick Lazenby — pipe changeover
  • Quorn Foods — unistrut / pipe supports
  • Butternut Box — spiral conveyor
  • Dovecoat Park — machine install

Each site card shows:
  • Typical job type, permit controller hint, doc stats (RAMS, PTW, drafts)
  • RAMS completeness badge (% readiness on latest RAMS)
  • Portal status: "on cloud" or "publish to cloud"
  • Job type override dropdown (optional — before starting job pack)

One-click actions per site:
  • Start full job pack — project + RAMS + MS + PTW from playbook
  • Repeat job — duplicate latest RAMS with new FESS job ref (e.g. FP1-DOLAV-2026-142)
  • Site pack — FESS Site Pack PDF (RAMS + 5-page MS + G&HP + LOTO + allergen + PTW)
  • Copy portal — client portal link for site permit controller
  • Mobilise site — G&HP + LOTO + contacts + today's briefing
  • Today briefing — mobilisation briefing for the site
  • Line clearance — jump to permits for that project
  • Project — open project hub

Header actions (full directory):
  • Seed site portals
  • Publish portals (N pending) — batch publish to cloud when signed in
  • FESS setup / Open full directory

5. RAMS — JOB STARTERS, BASELINE & TEMPLATE LIBRARY
--------------------------------------------------------------------------------

Nineteen FESS job starters (RAMS Builder Step 2, FESS org only).
All 22 MC reference PDFs in DOCS/FESS/Rams/MC are mapped (22/22 coverage).

Core MC-mapped starters (8 original):
  • DOLAV & MEYN station works (2SFG Scunthorpe)
  • Machine installation / placement
  • Spiral conveyor (Butternut Box)
  • Roof void pipe changeover (Cranswick)
  • Tank removal & relocation
  • RO room / water treatment works
  • Grille M&E (2SFG Flixton)
  • Unistrut / pipe support (Quorn)

Extended starters (8):
  • Enabling works, Mapress ring main, wash station upgrade
  • Compressor air drops, vacuum line install, cable containment
  • Cold room services, panel & lighting replacement

Additional MC parity starters (3):
  • FP1 works on site (2SFG Scunthorpe)
  • Various supplies (2SFG Scunthorpe)
  • Butternut production equipment install

Each starter includes:
  • Scope, method statement text, supplemental hazards
  • FESS job ref prefix (e.g. FP1-DOLAV-2026-xxx)
  • Suggested permit types
  • MC source PDF file references

Org-exclusive quick packs:
  • "Standard site RA baseline" — ~21 mapped M&E rows (pinned)
  • "FESS Excel RA baseline (verbatim)" — fess_001…fess_021 from Excel master
  • Five site-specific hazard add-on packs (2SFG, Cranswick, Quorn, Butternut, Dovecoat)

Per-site configuration (fessClientSites.js):
  • preferredBaselinePackId (Excel or mapped baseline per site)
  • extraHazardIds merged into job starter hazard set

RAMS Builder FESS features (Step 2 & 4):
  • Job starter picker + RAMS template library (search by client, site, PDF name)
  • Completeness badge — % score, missing expected hazards
  • Completeness gate before APPROVED/ISSUED (confirm if score < 85%)
  • FESS Excel RAMS print layout (auto for FESS org print/preview)

RAMS FESS-only fields:
  • fessJobStarterKey / fessJobStarterLabel
  • permitControllerName / permitControllerSignDate

MS auto-sync on RAMS save:
  • Linked method statement created or updated from RAMS scope and method steps

15. HOW TO VERIFY (FESS ORG)
--------------------------------------------------------------------------------

1. Log in as FESS Group organisation (fess-group).
2. Dashboard — confirm "FESS pulse" and "Client & sites" panels appear.
3. Switch to another org — confirm FESS panels and modules are hidden.
4. FESS setup — run checklist (profile, packs, G&HP, LOTO, sites, portals).
5. Client & sites — Seed site portals → Publish portals (when signed in).
6. Pick 2SFG Scunthorpe → Mobilise site → check G&HP, LOTO, contacts, briefing.
7. Optional: change job type → Start full job pack.
8. RAMS Builder Step 2 — job starter, template library, completeness badge.
9. RAMS Step 4 — completeness badge; print uses FESS Excel layout.
10. Save RAMS as issued — MS auto-syncs; completeness gate if < 85%.
11. FESS Site Pack — RAMS + MS + G&HP + LOTO + allergen + PTW in one PDF.
12. Client portal — copy link; permit controller approves RAMS.
